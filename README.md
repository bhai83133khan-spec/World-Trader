# Old World Trader — Offline Android Game

A lightweight, offline medieval merchant game. Buy goods in one port, sail to another, sell for profit, and purchase your own shop.

## Prototype gameplay
- 5 ports with different market prices
- Buy and sell 6 goods
- Cargo capacity limit
- Port-to-port sailing
- Shop purchase for 500 gold and stocking goods
- No network permission, account, ads, or API

## Build APK
Open **Actions** → **Build Old World Trader APK**. Download the `OldWorldTrader-debug-apk` artifact after a successful run.

Target: lightweight Android APK (50 MB goal; actual size must be checked after build).
